# Practice OS — Master Index

**What this is:** the front page of the strategy corpus. It organizes the 20 existing `research-practice-*.md` documents into the 13-part Practice OS, with a maturity score and disposition for each category. **This is an index, not a new analysis** — it adds navigation, not strategy.
**Date:** 2026-06-27 · **Status:** Living index (update scores as reality moves)
**Companion:** the Practice OS Audit (2026-06-27) that produced these scores.

> **Core diagnosis — "brain-rich, body-poor."** The practice has thought through almost the entire OS and externalized almost none of it. Average operational maturity ≈ **2.8/5** (= the self-assessed research-maturity level). "Think" functions score high; "do / sell / ship" functions score low.

> **⛔ The maintenance rule (from [execution-plan](research-practice-execution-plan.md)):** *No new strategy documents until the first invoice is banked.* This index is allowed because it **organizes** existing material. Do not let it spawn a 21st analysis. The next artifact after this should be a **sell-sheet** and **20 discovery interviews**, not more docs.

---

## How to use this index

1. Find the category you're working in below.
2. Open its **source docs** (already written — read, don't rewrite).
3. Check its **score + priority** to know whether the job is *publish it*, *validate it*, or *leave it alone*.
4. Respect the **disposition** (what's public vs. internal vs. deferred).

**Legend** — Score: 1 missing · 2 early · 3 partial · 4 strong/needs-integration · 5 operational. Int = in the docs · Pub = on the site / in market. Priority: Immediate (0–30d) · Near (1–3mo) · Mid (3–12mo) · Later (12mo+).
